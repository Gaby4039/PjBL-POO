# PjBL-POO
Repositório dedicado ao desenvolvimento do PjBL com interface gráfica.
Projeto: 

INTEGRANTES

1. Gabrielly da Silva Pereira
2. Giulia Manuelli Sitoni
3. Lucas Retzlaff dos Santos

O projeto consiste no desenvolvimento de um Jogo da Vida, o qual envolve um tabuleiro sequencial que simula a jornada da vida desde a faculdade ou início da carreira até aposentadoria. O objetivo é acumular a maior quantidade de dinheiro e experiências ao longo do caminho.
